# LitGraph

_1.0 · 本地优先的论文图谱与原文问答工作台_

[English](README.en.md) · [下载安装包](https://github.com/AOBI8001/LitGraph/releases/latest) · [产品网站](https://litgraph.aobi.qzz.io/) · [MIT](LICENSE)

把文献检索、原文整理、可视化探索和 AI 问答放在同一个工作空间。支持观点图与年份树、理论聚类与语义布局、2D / 3D 画布，以及围绕单篇、选中论文或整个项目的原文证据问答。

论文和项目在本机保存；远程 AI 功能需要用户自己的模型服务或外部 Agent。软件不附赠模型额度，也不意味着所有处理都离线。

## 📥 下载与安装

1. 打开 [GitHub Releases](https://github.com/AOBI8001/LitGraph/releases/latest)，下载 **LitGraph-Setup-1.0.0-x64.exe**。`Source code` 是源码，不是安装包。
2. 在 Windows 10 / 11 的 x64 电脑上运行安装程序，选择安装目录，完成后打开 LitGraph。不需要另外安装 Node.js 或 Python。
3. 首次打开是空白项目。选择“模型接入”配置 AI，或选择“样例数据”浏览 50 篇论文的图谱。

本版本**没有代码签名证书**。Windows / 浏览器可能显示“未知发布者”或安全警告。请只从本仓库下载，确认来源后再决定是否运行；不要关闭系统安全保护。可对照 Release 中的 `SHA256SUMS.txt` 核验文件是否完整：

```powershell
Get-FileHash .\LitGraph-Setup-1.0.0-x64.exe -Algorithm SHA256
```

校验和用于完整性核对，不能替代代码签名。可从 Windows“已安装的应用”卸载；普通卸载保留用户论文与配置，重新安装不会自动清空。当前不提供自动更新，升级时下载新的安装包。

## 🔌 接入 AI

### 方式 1：外部 Agent

在“设置 → 模型接入”中复制外部 Agent 接入文本，发送给本机可运行工具的 Codex、Claude Code 等 Agent。文本包含当前工作目录、规范文件和会话专用 MCP 连接信息。

Agent 按说明启动 MCP 适配器、完成握手并保持任务处理循环后，产品会弹出接入成功提示，右上角显示其报告的模型名称。桌面版提供适配器运行环境，不要求用户另装 Node.js。不同 Agent 的 MCP 配置入口不同；只把文本发给不能执行工具的普通聊天模型，不会建立连接。

连接文本含临时凭据，请勿公开。重新连接或关闭软件可能使旧连接失效。绿灯只代表近期连接状态，不验证 Agent 的真实身份；Agent 停止处理任务后，产品无法替它继续工作。

### 方式 2：模型 API

填写服务地址、API Key 和模型，测试并保存。支持 OpenAI-compatible Chat Completions / Responses 和 Anthropic Messages 协议；DeepSeek、Qwen、Kimi 等需要选择服务商实际支持的接口与模型。

桌面版加密保存 API 配置，并由本机进程发请求，避免网页跨域限制。是否支持图片需要按模型能力确认。连接测试成功不代表该模型具备联网、图片理解或无限上下文能力；检索和下载由 LitGraph 工具完成。调用费用、速率和地区限制由模型服务商决定。

## 🧭 使用流程

### 1. 建立项目

左上角菜单支持新建、重命名、切换和删除项目。可以选择样例、发现文献或导入自己的论文。公共样例包含 50 篇论文的元数据和摘要，图谱总结与部分关系由 AI 整理，不能直接当作经验证的学术结论。样例不附带私人 PDF / Markdown 全文；论文原文与第三方摘要不属于软件的 MIT 授权内容。

### 2. 发现并导入文献

1. 描述研究主题，填写年份，选择语言、文献类型、获取方式和排序。
2. “检索数量”提供 **5 / 10 / 20 / 50 / 100**，也支持 5–100 的自定义整数。
3. AI 规划检索词；软件从 **OpenAlex、Europe PMC、Crossref** 获取真实记录，执行筛选、去重，再由 AI 判断相关性。
4. 在右侧确认结果，只导入自己选中的文献。
5. 软件补全可获取的标题、作者、DOI、年份、摘要、参考文献与被引信息，尝试下载合法可获取的 PDF，提取文本保存为 Markdown，并绑定节点的“原文”按钮。

“开放获取”不是某一个独立搜索引擎；它要求可公开获取的文献。“机构登录”用于填写并打开机构图书馆入口，**不会自动读取浏览器 Cookie，也不会绕过付费墙或机构限额**。无法自动取得的原文可由用户合法下载后导入。

检索数量是目标数量，不保证全部找到或全部取得全文。被引量是数据源提供的计数，不是软件从 PDF 自行数出来的数值；缺失时保持未知，不编造为零。不同平台的收录范围与计数可能不同。

### 3. 探索图谱

| 功能 | 操作和含义 |
| --- | --- |
| 观点图 | 以理论聚落或语义相似性组织论文，观察支持、反对及相关关系 |
| 年份树 | 按发表年份观察分布与关系；年份间距可调 |
| 2D / 3D | 切换空间维度；观点图 3D 拖动空白处旋转模型，年份树 3D 使用平移为主的镜头操作 |
| 3D 键盘 | 方向键 / WASD 移动镜头，滚轮缩放；画布显示操作提示 |
| 节点 | 悬停看信息；点击选中、打开详情并显示关联线，再点同一节点取消 |
| 多选 / 框选 | 批量选中后进入研究空间；退出选择模式清除选中 |
| 筛选 / 数据 | 筛选图谱、查看统计或编辑表格数据 |
| 外观 | 中英文、日间 / 夜间、八种独立画布背景；主题切换将背景重置为白 / 黑 |

节点保留所属理论的颜色；没有全文不意味着去掉节点颜色。切换查看方式、布局或图谱类型会清除当前选择。图中的相关性不能直接解释为因果关系。

### 4. 围绕原文提问

研究空间支持全部论文、单篇和选中论文标签页；输入问题后 **Enter 发送，Shift+Enter 换行**。窗口可拖动、调整大小，附件可拖入发送框。

“快速”偏向简短、低等待的回答，“专家”偏向充分分析；这是深度与速度偏好，不是固定模型名称，也不能保证固定响应时间。等待期间显示耗时；暂停会取消当前请求，之后可重新提交该问题，不能恢复服务商内部已经中断的思考状态。

系统从本地 Markdown / 原文中检索相关片段，要求回答基于这些证据，AI 推断额外标出。默认不强制展示冗长引文。回答后可给出三个与本次内容相关的简短追问，点击即可继续。缺少全文时必须说明摘要级限制，不能假装已阅读全文。

## 🔐 本地数据与隐私

Windows 桌面版数据位于 `%APPDATA%\litgraph`（独立于安装目录）：

| 内容 | 文件或目录 |
| --- | --- |
| 项目、界面设置、对话状态 | `workspace-state.json` |
| 操作系统加密的 API 配置 | `model-config.encrypted` |
| PDF、Markdown、来源索引 | `projects/local-fulltext-index/` |
| 文献发现导入快照 | `projects/local-projects/` |
| 外部 Agent 规范与适配器 | `agent-guide/` |
| 随机安装标识和待发送基础统计 | `metrics-state.json` |

迁移前关闭软件并备份完整数据目录。项目 JSON 不包含全部原文；系统加密的模型配置不能保证换电脑可解密，迁移后应重新填写。不要公开自己的数据目录、API Key 或 Agent 接入文本。

官方桌面版默认发送随机安装标识、事件编号、打开/使用类型及时间，用于统计首次使用、每日活跃安装、打开与核心操作次数；不发送论文、对话、密钥、文件路径、硬件标识或具体操作名称。可在“设置 → 关于 LitGraph”关闭。详见 [隐私说明](PRIVACY.md) 与 [统计说明](docs/metrics.md)。

## 🧠 算法与优化

- **理论布局**：根据节点的理论归属和关系进行力导向排列；节点大小、间距、颜色和连线可调。
- **语义布局**：本地词项特征与相似度计算驱动布局，不应误称为付费模型生成的嵌入向量服务。
- **年份树**：将时间与关系结合呈现，不把先后发表自动解释为引用或因果。
- **原文问答**：本地分块、词项匹配与相关片段排序组成检索增强生成（RAG）；当前不是向量数据库检索，也不能保证一次请求通读全部论文。
- **清晰度与性能**：画布按有效像素比例渲染，3D 按需加载，背景纹理缓存；模型请求分批处理，任务取消和过期结果隔离避免旧回答覆盖新状态。
- **服务边界**：本机服务使用会话凭据区分网页与 Agent；下载执行公开地址校验、重定向限制与体积限制。

扫描 PDF 尚无内置 OCR；复杂多栏、公式、表格可能提取不完整。服务商网络、权限、上下文与限流仍可能影响检索或回答。AI 结论需要核验，软件测试不代表所有电脑、所有模型和所有论文都不会出现问题。

## 🛠️ 源码运行与构建

需要 Node.js **22.12+** 和 pnpm：

```sh
git clone https://github.com/AOBI8001/LitGraph.git
cd LitGraph
pnpm install --frozen-lockfile
pnpm dev
```

开发网页通常为 [http://127.0.0.1:4320/](http://127.0.0.1:4320/)，以终端实际端口为准。仅绑定本机，不要把开发服务直接开放到公网。

```sh
pnpm test
pnpm build
pnpm test:desktop
pnpm check:release
pnpm dist:win
```

Windows 构建产物位于 `release/`，不自动上传。桌面测试使用独立临时数据和虚拟凭据，不发送生产统计。网页开发预览使用浏览器存储，API Key 不具备桌面版相同的系统加密保护。

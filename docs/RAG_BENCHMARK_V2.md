# LitGraph-RAG-50 v2 评测方案

## 范围与冻结规则

使用样例项目的 50 个节点和本地 MD。paper-045、paper-046 对应同一论文，因此主要分析按 **49 篇独立论文**计。不是文献发现召回测试，也不比较开放获取/机构渠道。

- 49 道单篇事实题，每篇独立论文一道。
- 20 道指定两篇论文的比较题，覆盖样本、人群、方法、操作与结论。
- 1 道重复论文控制题，不进入主要指标。
- 5 道不可回答题，单列；其中银行账号问题属于安全拒答控制，其余 4 题才主要考察知识边界。
- 共 75 次问答，主要准确率分母 69，参考证据召回分母 89。

这些是本项目定制的固定语料回归题，不是公开行业标准测评，也不是按论文独立留出的外部泛化集。比较题通常明确提供两篇标题，测试允许利用这个真实用户输入限定论文范围，不等于无标题的全库开放研究问题。

测试前另设 12 道开发题（8 单篇、4 比较），询问不同事实。只用开发题选择 k；正式题冻结后不依据其失败案例改参重跑。本次比较 k=8/12/20/32/48，以固定字符预算下证据召回最高、k 最小为规则，选出 k=20。开发题与正式题使用同一语料，因此不是完全无污染的未知论文测试。

## 实际执行

研究空间同一查询计划与回答规范；本地 E5 量化模型、BM25、多查询融合和特征重排。快速偏好，正文预算 28,000 字符，top-k=20。Codex CLI 使用当前默认模型，不强制切换；本次输出不提供可核验的精确模型 ID，所以报告为“Codex CLI 默认模型（具体 ID 未披露）”，不得写成某个 GPT 型号。

每题先生成双层关键词/多查询，再实际检索 MD，再把证据交给模型生成答案。并发 2 个任务，每题只执行一次，不重试挑选答案。返回失败计入失败，不删题。代码、语料索引和题目保存哈希，原始问题、改写、上下文、答案、耗时逐题落盘。生成过程不允许调用网页/文件工具绕过给定证据。

本次实际跑的是 Codex 通道；API 共享规范及本地检索，但没有对每种 API 模型重复测评。不能把此成绩当作 DeepSeek、Claude、Kimi 等所有模型的统一成绩。

## 指标定义

1. **严格答案准确率**：所问必要事实全部正确计 1；部分正确计 0.5；错误、无答案、技术失败计 0。严格准确率只把 1 计为正确；部分分单列加权分，不替换主指标。
2. **参考证据召回率**：每个被问论文预先标注一个正文参考位置；被送入模型的 chunk 对该位置覆盖至少 80% 视作召回。比较题每篇各一个。按唯一论文及原始字符偏移匹配，重复节点映射到同一论文。
3. **参考段落命中精度**：命中这些稀疏标注的 chunk / 所有返回 chunk。未标注片段不一定无关，因此这个数值**不是完整语义 Precision、不是答案准确率、不是幻觉率**。
4. **拒答、运行和格式**：不可回答题是否拒绝编造，调用是否完成，JSON 及三个后续问题是否满足格式，引用 ID 是否有效、有可定位行号。编号有效不能替代引用蕴含判断。
5. **时延**：分别记录改写、检索、回答和总耗时的中位数/P95。缓存冷热混合，2 路并发；总题耗时之和不是墙钟耗时。与旧版并发 1 的时延不是严格受控对照。

执行助手对照原文逐题判定，**尚无独立人工/领域专家复核**。Wilson 95% 区间仅作描述：题目来自相关主题、共享论文，不完全独立，不能把区间当作任意真实问题的保证。

## 保留歧义，不事后粉饰

- Q02、Q03 原文不同位置存在时间或年龄差异，能够正确区分两处说法的答案可得分。
- Q47 的旧题表述没明确“本研究而非引述结果”，另报排除此题的对照。
- C18 问“另一个调节因素”不唯一。冻结目标是“在场类型”，模型答“个体差异”，原文确实支持后者；主表按目标计部分正确，同时报告排除此题结果，不能把它称作无依据幻觉。
- N01 有安全拒答因素，另报去掉此控制后的 4 道拒答题。

## 产物

`output/rag-benchmark-v2/` 保存 settings.json、gold.json、每题原始 JSON、audit.json、cases.csv、summary.json 和 REPORT.zh.md；开发调参保存于 `output/rag-v2-development/`。评分脚本绑定已审阅答案指纹；更换模型/答案后必须重新审阅，不能复用旧分数。

原始上下文包含本地论文内容，默认不提交 GitHub。MD 可用于本机研究问答不等于有权公开再分发全文。对外只发布经过检查的统计、方法和不包含受限正文的数据。

正式回答冻结后，单独修正中文句末标点后不带空格的分块情况，并将网页向量推理迁到同模型的本机 CPU 工作进程。不是依据正式题 bad case 调整排名。另用冻结计划重放全部 75 题，检查中文规则是否改变样例分块、温热缓存下排序与召回是否变化，记录于 `context-replay.json`。原始回答评分始终绑定原始上下文，不能把原答案套在重放的新证据编号上，也不能把检索重放称作第二轮问答准确率。原始哈希保留，不覆盖测试历史。

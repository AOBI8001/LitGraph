# LitGraph-RAG-50 v1 — 评测规范

## 范围与冻结规则

这是针对研究空间的内部、可复现基线，不是文献发现或下载测试，也不是第三方认证。固定使用样例的 50 个节点、49 篇不同论文及其 MD 原文。`paper-045` 与 `paper-046` 重复，后者作为重复控制题，不进入主要得分。

题集共 60 题：49 道不同论文的事实题、1 道重复控制题、5 道跨论文信息比较题、5 道库内不可回答题。事实题覆盖数值、样本、方法、研究结论等；主要是明确陈述的信息，不代表复杂综述或开放式推理能力。题目由原文构造，现有 AI 总结不作为金标准。问题以中文提出，论文主要是英文。

运行前写入题目、参考答案、最小支持片段、原文位置及文件哈希。保留软件版本、检索代码与提示词哈希。基线期间不优化检索器、不根据回答修改题目；发现参考答案有歧义时，单列审计说明。

## 实际执行配置

- 主测试：每题都以全部 50 个节点为候选范围；题目明确指出目标论文。
- 速度偏好：当前产品默认的快速模式，原文预算 28,000 字符。
- 检索与提示：直接调用产品的 `selectEvidence`、`researchMessages`，保持默认规则。
- 生成：调用产品的 Codex 外部 Agent 程序，每题独立、无历史对话、禁用工具和网络检索。使用官方 CLI 默认模型，不覆盖模型设置；如果接口未返回确切模型标识，报告为未知，不能臆测。
- 每题运行一次，不自动重试。网络超时等运行故障单列，不能作为回答内容错误来掩盖。
- 诊断对照：对 49 道事实题额外运行“只选中该论文”的检索，但不把其检索结果冒充完整问答准确率。

## 指标定义

### 1. 标注证据召回率

每道事实题有一个预先标注的最小支持片段，跨论文题有两个。实际发送的上下文覆盖一个片段至少 80% 的字符时，计为找回。以去重论文身份匹配片段，避免重复节点双重计数。

总体召回率 = 找回的标注片段数 ÷ 所需标注片段总数。主要 54 道可回答题共有 59 个片段。另列单题宏平均与原文字符覆盖率。

这是**指定参考片段的召回率**，并非所有语义等价证据的完备召回率；同一事实可能在原文其他位置出现。

### 2. 标注证据精确率

检索片段与目标原文的金标准片段有实质重叠，才计为命中：重叠字符至少达到 `min(20, 金标准片段长度的一半)`。精确率 = 命中片段数 ÷ 实际发送片段数。

该指标采用稀疏的参考片段标注，是保守的“参考证据命中精度”，不能解释为所有其余文本都毫无相关性，也不能把其补数称作幻觉率。重复参考、背景、作者信息与其他论文文本可能占用上下文，但不能替代题目所需证据。

### 3. 回答正确率

逐题对照原文审计，而非只做字符串匹配：

- **正确（1 分）**：回答包含所有所需事实，数量、组别、方向与原文一致，没有改变结论的额外错误。
- **部分正确（0.5 分）**：只答出部分所需事实，或明确缺少其中一部分；没有捏造其余部分。
- **错误 / 未答出（0 分）**：核心事实错误、张冠李戴，或本来可回答却因检索不足未能回答。

主要指标为严格正确率：完全正确题数 ÷ 54。部分得分率另列。回答“证据不足”可能是忠于当前上下文的表现，但对端到端可回答题仍计为未答出；不要把诚实拒答称为幻觉。

审阅由执行本评测的 AI 助手完成，参考答案也未经独立领域专家复核。因此结果应称为内部实测，不应声称人工盲评或客观权威结论。原文与抽取文本本身可能存在冲突或乱码，需逐题保留说明。

### 4. 不可回答题、格式与时延

- 不可回答题：明确说明库内没有依据且不编造目标事实，计为正确拒答。5 题单独统计，不用于抬高主要正确率。
- 输出格式：JSON 可解析，`answer` 为非空文本，`suggested_followups` 为 3 个问题。
- 时延：报告完成题的中位数、P95，并单列超时。
- 输出内容没有直接原文引用不等于不忠实；产品默认允许不展示引文。

## 复现与产物

题集：`tests/benchmarks/rag-gold.mjs`。执行器：`tests/benchmarks/run-rag.mjs`。

结果仅写入被 Git 忽略的 `output/rag-benchmark/`：冻结设置、金标准片段、检索上下文、每题请求和响应、使用量（如接口返回）、逐题评分与汇总报告。不要公开上传含论文全文的原始请求包或个人配置。

最终报告必须同时给出成功、拒答、错误和代表性失败案例。单次小规模自建题集的分数只适用于这套语料、问题、配置与接入方式，不能推广为任意模型、任意论文或全部产品功能的准确率。

`summarize-rag.mjs` 保存本轮逐题审计决定，并校验被审阅回答的哈希。新模型或新版本生成新回答后，必须重新审阅评分，不能沿用旧答案的分数。无答案题目前较容易，后续应补充主题相近但原文缺失的困难问题；这属于新版题集，不回改本轮基线。

# 1.2.6：质量与耗时回归实测

测量日期：2026-09-13。沿用 LitGraph-RAG-50 v2 固定题集、语料与评分口径，不是行业标准或未知问题盲测。正式运行开始后，检索与生成代码哈希未改变；每题运行一次，无重试挑选。

## 核心结果

| 指标 | 早期 v2 记录 | 1.2.5 重测 | 1.2.6 本次 |
| --- | ---: | ---: | ---: |
| 参考证据召回 | 84/89 · 94.38% | 72/89 · 80.90% | **87/89 · 97.75%** |
| 严格答案准确率 | 66/69 · 95.65% | 60/69 · 86.96% | **69/69 · 100%** |
| 单篇事实题 | 49/49 | 45/49 | **49/49** |
| 跨论文比较题 | 17/20 | 15/20 | **20/20** |
| 完整回答后端耗时中位数 | 37.672 秒 | 12.112 秒 | **20.599 秒** |
| 完整回答后端耗时 P95 | 50.209 秒 | 17.119 秒 | **24.885 秒** |

相对 1.2.5，本次中位数增加约 **8.49 秒**，参考证据召回提高约 **16.85 个百分点**，严格准确率提高约 **13.04 个百分点**。这是这些实际运行的观测对比，不是排除网络、模型版本和运行环境影响后的纯因果估计。原先希望控制在 15–20 秒的中位数，本次为 20.60 秒，略高于这个区间；没有删掉较慢题来达标。

运行成功与 JSON 格式均为 **75/75**；不可回答控制题 **5/5**（其中一题有隐私拒答因素）；无未知证据编号，无规划降级，无向量检索降级。重复论文控制题正确，但不计入主要准确率。

## 什么被测到了

50 个样例节点，其中 045/046 是同一论文，主要语料按 49 篇独立论文计算。共 49 道单篇事实题、20 道指定两篇标题的比较题、1 道重复控制、5 道不可回答题。主要准确率分母 69；参考证据召回分母 89。必要事实全部正确计 1，部分正确计 0.5；严格指标仅计满分。参考位置被提供给模型的完整片段覆盖至少 80% 才计召回。

**C04 和 C17** 各有一篇没有覆盖冻结参考位置，但答案使用其他真实原文位置分别正确报告了人数与保持时长/发音条件。因此，两题答案正确，参考召回仍各按 1/2 计算，不事后移动参考位置。参考位置是稀疏标注；此召回不是检索结果语义 Precision，也不等于答案准确率。

使用真实 **Codex CLI 当前默认模型（精确模型 ID 未披露）**，低思考强度、独立无工具模式，并发 2。规划、检索、回答均实际执行，不是回放旧答案。API 与 CLI 共用检索和提示契约；**本次未用 DeepSeek 等其他模型重复这 75 题**，不能将成绩外推为所有模型的统一准确率。

## 耗时口径与实现

| 阶段 | 中位数 | P95 |
| --- | ---: | ---: |
| 查询规划 | 9.477 秒 | 11.707 秒 |
| 本地检索与证据编排 | 0.154 秒 | 0.966 秒 |
| 模型完整回答 | 10.847 秒 | 13.448 秒 |
| 后端总计 | 20.599 秒 | 24.885 秒 |

分项中位数不可直接相加。总计不含首次语料读取/索引准备、桌面渲染和其他用户请求排队；不是点击发送到屏幕显示的完整 SLA。隔离的新测试缓存中，50 个节点的 3,225 个片段索引在提问前全部就绪，准备耗时 15.189 秒，单列而非隐去。75 题两路并行的总墙钟为 792.571 秒。

精确事实和比较问题使用精简、限时的多查询规划，基础 20 段/28,000 字符；按明确论文目标分配证据，并用一轮本地查询维度/摘要/开头原文补检，最多增加 6 段/8,400 字符。简单概念问题仍使用本地词汇扩展。回答阶段只查询已就绪索引，不等待整库生成段落向量。

## 局限与复现

- 本次达到固定回归集 100% 答案准确率，**不代表产品对所有问题均为 100%，也不保证泛化到任意用户项目能达到 95%**。
- 修复参考了 1.2.5 的已知失败表现。开发集使用同一语料的 12 个不同问题、16 个证据位置，最终开发运行找回 16/16。正式集是已知回归集，不能称作未见测试集；仍需要不同领域语料、新问题与独立审阅。
- 执行助手逐题对照冻结标准与原文判定，尚无独立人工/领域专家复核。必要事实评分不能替代每条附加表述的完整引用蕴含审计。
- 模型的实时默认版本无法精确锁定，网络及其他本机负载也不完全相同；这不是严格随机对照实验。大项目、OCR 噪声、没有明确论文标题的开放问题仍需另外测试。

运行：在具有同版本样例 MD、内置模型及向量资源的工作目录执行 `node tests/benchmarks/rag-current.mjs`；`--development` 仅测试开发题的真实规划与检索，不计答案准确率。需要当前设备已登录 Codex；若设备依赖网络代理，应沿用其代理配置，不把代理地址或凭据写入源码。

每题原始输出、证据包、哈希和用时写入隔离的 `output/rag-benchmark-126-*/`。审阅全部新答案后创建与答案指纹绑定的 `review.json`，运行 `node tests/benchmarks/summarize-current.mjs <本次目录>` 汇总；不能复用旧答案的评分。

## English summary

On the same known 75-request regression suite, 1.2.6 recovered 87/89 reference units (97.75%) and answered all 69 primary questions correctly under the frozen necessary-fact rubric. Median backend completion latency was 20.599 seconds, versus 12.112 for 1.2.5; P95 was 24.885 seconds. All five negative controls passed. No invalid evidence IDs or retrieval/planning fallbacks occurred.

These are real Codex CLI runs, not an all-model guarantee or unseen-corpus evaluation. The executing assistant adjudicated answers; independent human review is still required. Cold corpus/index preparation, UI rendering and user queueing are excluded from per-question latency and reported separately above.

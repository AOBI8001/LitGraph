# 本地导入的文献信息识别

文献信息识别与全文分析分别记录状态。即使暂停导入、模型未接入或鉴权失败，已确认的标题、作者、年份也在转换阶段保存。

默认顺序为：PDF 原生文字与版面识别 → DOI / 精确标题匹配学术记录 → 当前模型的纯文本字段补全。这个流程不要求模型支持图像或 OCR。PDF 内容流不一定按照视觉位置排列。转换正文时继续保留原有行序及引用定位；另存前八页的文字位置、字号和少量 PDF 描述字段，供标题和署名识别使用。文件名及 PDF Info / XMP 只作为线索，字段需要在原文中核对。描述性文件名也可作为在线检索词，但必须同时匹配完整标题和文件名中的作者才采用学术记录，不直接接受首条搜索结果。规则会跳过资料库封面中的个人主页、栏目、导师、参考文献和接收日期等信息；仅在定位不冲突且可给出原句依据时使用模型补全，包括缺失的年份。

发表年份优先取卷期、文章编号和明确出版日期，避免把页码、研究中提及的年份、PDF 创建时间或下载时间当成发表年份。原文语言和手动编辑优先保留，精确学术记录中的翻译标题、罗马化作者名可以存为别名。来源不足时保持待确认，不用当前年份填补。

OCR 不在默认导入、启动修复或重新识别流程中执行。Windows 中，用户可主动点击“可选：本机 OCR 核对封面”，使用已安装的系统识别语言，最多检查前三页，不向第三方发送图像；临时图像用完删除。该功能不等于把整篇扫描件转换为可信全文。macOS 本测试版没有同等 OCR 后备能力，缺失字段仍可人工核对。如果原文、学术记录和描述性文件名都没有可靠信息，会明确保留待确认，禁止让文字模型猜测图像中不存在于文字层的信息。

打开旧项目时会补读保留的 PDF 版面并更新可确认字段。此步骤不重写已转换的 Markdown，不改动引用行号，也不重建全文向量索引。原文替换会清除旧版面缓存。无法可靠转换的全文仍明确提示需要补充可读原文，文献信息检索与纯文本补全仍独立执行。模型和查询结果按原文、版面及模型标识缓存；网络或模型临时失败可以重试，主动重新识别也会重新核对。

可用实际 PDF 目录复现隔离导入测试：

```powershell
node tests/desktop-metadata-corpus.mjs '<PDF目录>'
```

默认关闭模型和在线元数据请求。设置 `LITGRAPH_METADATA_ONLINE=1` 可以测试公开学术记录的补全，但不会读取现有个人模型配置。可选的第二个参数是人工核验过的 expected.json：以文件名为键，值包含 title、authors、year；有合法署名简称、译名或线上/卷期日期差异时，可用 titles、authorSets、years 明确列出允许值。测试分别记录原文完整保留、全文转换、字段补齐和与人工标签一致的数量；字段被填满不自动等于识别正确。测试文件和报告仅保存在忽略的 output/ 目录。

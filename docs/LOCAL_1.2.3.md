# LitGraph 1.2.3 本地测试版

本版仅提供本地安装包，未推送 GitHub。安装前退出 LitGraph；覆盖安装不会主动清除研究数据。无需重新导入已有论文。

## 全文问答

- 片段合并：在同页、同部分和同标题内合并较短段落，保留原文偏移、页码和行号，不跨页或跨章节拼接。过长段落仍按句子边界切分。
- 提前建索引：MD 保存后后台排队；启动时继续处理已有项目。索引按正文内容、切分版本及向量模型版本校验，分批保存检查点。论文分析与全文索引不再共用一个“完成”计数。
- 提问只查已就绪的向量，不在回答过程中为整个资料库生成向量。背景索引批次之间优先处理提问。
- 快速模式：使用本地关键词扩展，不额外等待一次模型改写；多篇向量检索预算 3.5 秒、单篇 1.2 秒，超时或索引未完成时使用可用向量和关键词证据。这个预算不是完整回答时间的保证；加载、切分、关键词处理和上游模型生成仍有独立耗时。
- 快速模式默认最多提供单篇 6 段、多篇 12 段证据，避免没有命中时把整个项目的所有摘要发送给模型。专家模式保留多查询改写与较大证据预算。
- API 支持真实 SSE 增量显示；只显示回答正文，不显示模型推理内容。最后仍验证回答 JSON 和证据引用。外部 Agent 在其 CLI 提供回答增量事件时显示增量；只返回最终结果的 CLI 无法保证逐字流式。
- 研究空间显示 MD、分析、全文索引和片段进度，可暂停、继续和重试后台索引。首次升级时新切分规则会触发补建，补建不阻塞问答。

## 项目与设置

- 研究空间的历史、范围标签页和输入草稿按项目分开。切换项目会取消旧项目尚在执行的问答并关闭旧窗口。
- 旧版没有项目归属的遗留问答不再自动混入当前项目；原记录保留在数据中。
- 设置顺序：数据文件夹 → 还原所有设置 → 清除数据。
- 还原设置保留研究资料；清除数据需二次确认，并要求先暂停导入和问答。
- 清除数据将本机用户研究资料和旧版全文缓存移至系统回收站，清除问答、摘要批注和导入历史；样例、随软件附带的模型及模型连接配置保留。原始导入来源文件夹不受影响。

## 验证口径

2026-09-12，本机只读对比当前项目的 280 份 MD：旧切分产生 105,923 段，新切分产生 25,755 段，减少约 76%。不足 90 字的片段从 67,448 减至 1,732，剩余短段主要受章节和页边界约束。

对同批正文故意模拟向量检索不返回，验证关键词降级：29 篇约 3.55 秒，280 篇约 4.10 秒完成本地证据检索。此结果不包含真实 DeepSeek API 或 Codex 的最终回答生成时间，也不表示新的准确率、召回率已完成评估。

95 项单元与服务测试通过。独立桌面测试验证真实 SSE 在响应结束前显示、快速模式仅一次回答调用、项目 A/B 历史隔离、设置顺序、取消清除、确认清除后恢复 50 篇自带样例及保留模型配置。另通过桌面启动与持久化、大批量导入回归。所有清除测试都在隔离的人工测试资料中执行，未清除用户当前项目。

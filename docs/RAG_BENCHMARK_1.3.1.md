# LitGraph 1.3.1 跨论文比较专项回归

## 范围

- 语料：内置 50 个样例节点，其中 49 篇为独立论文。
- 题集：冻结的 20 道跨论文比较题，覆盖样本、人群、方法、操作、测量与结论。
- 模型：本机配置的 DeepSeek V4.1 Flash API。
- 执行：快速与专家模式各 20 次，共 40 次；顺序运行，单题不重试，不使用外部 Agent。

## 结果

| 指标 | 快速 | 专家 | 合并 |
|---|---:|---:|---:|
| 问题级准确率 | 19/20 = 95% | 19/20 = 95% | 38/40 = 95% |
| 语义证据召回率 | 19/20 = 95% | 19/20 = 95% | 38/40 = 95% |
| 冻结片段严格召回率 | 32/40 = 80% | 32/40 = 80% | 64/80 = 80% |
| 完成率 | 20/20 = 100% | 20/20 = 100% | 40/40 = 100% |
| 无效引用 | 0 | 0 | 0 |
| 首字中位数 | 2.12 秒 | 2.91 秒 | — |
| 完整回答中位数 | 4.36 秒 | 5.11 秒 | — |

优化前相同题集的合并问题级准确率为 67.5%，语义证据召回率为 62.5%，冻结片段严格召回率为 65%。本轮分别达到 95%、95% 和 80%。

## 实现变化

比较问题先由查询规划拆成独立维度。系统为每个适用的“论文 × 比较维度”单元单独检索候选、在单元内重排，并最多选择一条最佳原文证据；相同原文能够支持多个维度时只进入上下文一次。最终模型接收完整的维度矩阵、允许使用的证据编号和证据不足单元，不允许用其他论文的内容补写空缺。

专项重排增加了样本量、分组人数、年龄、双胞胎配对、剂量、时长、研究数量、测量定义和效应方向等原文特征，同时降低参考文献段和高数字密度表格的噪声权重。

## 指标口径与限制

- 问题级准确率要求必要比较事实正确；只答对部分对象或维度不计完全正确。
- 语义证据召回允许找到能够支持同一事实的等价原文位置。
- 冻结片段严格召回只承认预先冻结的参考位置，因此比语义召回更保守。
- 题集来自已知样例语料，适合检查版本回归，不是公开行业基准，也不是独立领域泛化测试。
- 延迟包含当前模型服务与网络状况；不能视为固定 SLA。
